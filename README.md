A simple, modern, and fast web API built with FastAPI and Python. 
This project demonstrates RESTful API development with best practices.

Features:
- FastAPI Framework - High performance, easy to learn, fast to code
- Automatic API Documentation - Interactive Swagger UI and ReDoc
- Type Hints - Full Python type hints support
- Async Ready - Built-in async/await support
- Validation - Request/response validation using Pydantic models
- Dependency Injection - Easy-to-use dependency injection system
